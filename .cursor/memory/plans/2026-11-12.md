## 让 Actor 蓝图能接巡逻组件事件（patrol-presentation 可执行）

### 1. Summary

给 `UTestEnemyPatrolComponent` 的三个表现事件补一组 `UPROPERTY(BlueprintAssignable)` 多播委托，使 `BP_TestEnemy` 能在自己的 EventGraph 里用「Bind Event to OnPatrolDyn」直接接线——不再需要「覆写父类函数」，也不依赖 monolith 词表里不存在的节点类型。落点 `AIAgentProject/Source/AIAgentProject/{Public,Private}/TestEnemyPatrolComponent.*`。仿 `PlatformProgressComponent`（同项目、委托 + BlueprintImplementableEvent 并存）。

### 3. 已确认决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 职责放哪 | 委托声明在 `UTestEnemyPatrolComponent`；绑定动作在 BP_TestEnemy 的 EventGraph | 玩法/事件源在组件（conventions.md:8）；接线是表现，归蓝图 |
| 仿谁 | `PlatformProgressComponent` 的 Dyn 委托写法 | 同项目、同组件基类、已验证可在蓝图绑定 |
| 不改谁 | `TestEnemy.h/.cpp`、`TestEnemyPatrolTest.cpp`、`Build.cs`、三个现有 BMP 事件 | 测试只读 `MeleeAttackCount`；删 BMP 会破现有蓝图与向后兼容 |
| 使用约束 | 委托必须 `DECLARE_DYNAMIC_MULTICAST_DELEGATE`（动态多播），否则蓝图不可绑；接口桥接层的 `BindToEventProperty` 要求 `component_name` + `delegate_property_name`（`core/monolith_bridge.py:596-600`），属性名须以 `Dyn` 结尾以示与 BMP 事件区分 | 桥接层已支持这条路，无需改 Python |

### 4. Proposed Changes

- **修改** `Public/TestEnemyPatrolComponent.h`
  - 文件头（`#include "TestEnemyPatrolComponent.generated.h"` 之后、`UCLASS` 之前）加三条声明：
    ```cpp
    DECLARE_DYNAMIC_MULTICAST_DELEGATE(FTestEnemyPatrolSignature);
    DECLARE_DYNAMIC_MULTICAST_DELEGATE(FTestEnemyChaseSignature);
    DECLARE_DYNAMIC_MULTICAST_DELEGATE(FTestEnemyMeleeSignature);
    ```

    UPROPERTY(BlueprintAssignable, Category = "Test")
    FTestEnemyChaseSignature OnChaseDyn;
