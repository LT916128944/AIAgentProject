## 2. 模块统一接口（与 `agent/umg_spec.py` 同形）

`KIND / JUDGE_KIND / SPEC_HINT`；`validate_spec(spec)->list`；`plan_ops(spec)->list[dict]`（确定性、幂等、无时间/随机）；`exec_op(op, call, write)->{ok,tools,readback,error}`（**只经注入的 `call` 调工具，顶层不 import 编辑器**）；`assertions / verify_spec(spec, readback)`（`sp.eval_assertions` 只读复核）；`extract_spec / write_task / recognize / summarize`；`build(step, **kw)=sp.build_domain(module, step, **kw)`。
