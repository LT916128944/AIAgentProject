- 口径补充（与卡面字面的差异，已按实现收口）：
  1. **DSH 投影字段映射**：卡面只说「缓存字段有则写」。DSH 的 `tokenUsage` 投影给的是 `uncachedInputTokens` / `outputTokens` / `cacheReadTokens` / `cacheWriteTokens`，与 DeepSeek 原生字段不同名。取 `prompt_tokens = uncachedInputTokens + cacheReadTokens`，`cacheReadTokens → prompt_cache_hit_tokens` 与 `cached_tokens`，`uncachedInputTokens → prompt_cache_miss_tokens`。`cacheWriteTokens`（本次写进缓存的量）在 DeepSeek 账里没有对应字段，不硬套成 miss，不抄。
  2. **`elapsed` 不写**：DSH 导出里没有耗时，按「不估算、不填 0」直接不写该键（`core/llm_call.py` 的行有它，但那是真实计时）。
