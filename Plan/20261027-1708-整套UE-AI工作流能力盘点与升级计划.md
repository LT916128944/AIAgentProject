## 4. 升级计划（分四批，每批可独立停）

### U0 · Monolith 后端健康与一次重试（P0，0.5–1 天，对应 G5）

9316 的 502 已经把一次诊断句整句打挂。这是当前最便宜、最先挡路的事。

- `backends/monolith.py` 的 `exec`：连接类错误（502/超时/ConnectionError）允许**一次**立即重试（铁律「遇错即停：最多重试一次」的额度用在连接层，不动业务层语义）；重试仍失败则错误原文追加一行固定指引：「检查 UnrealEditor 是否在跑、Monolith 插件日志是否有 `listening on port 9316`」。
- `discover` 前可加一次轻量健康探测（一个只读 action 或 HTTP 探活），失败直接给指引，不消耗 8 次调用预算。
- 把 502 这类故障按 `failure_class=mcp_down` 记进 `failure_patterns.json` / `ue_errors.jsonl` 的现有通道，让 `fix` 查得到。
- 离线检查：新增 `eval/check_backend_health.py`（mock HTTP，断言 502 重试一次、二次失败带指引、不回退 8000）。

验收：`check_backend_health.py` 打印 ok；`check_routes.py` 仍绿；`.env` 不动。

### U3 · level-assembly-persist 整句收口 —— ⛔ 尝试一次，被两个新钉住的缺陷挡住（2026-10-27）

执行了真实整句 run（run `data/runs/20261027/20261027-180955`）：「打开编辑器，打开关卡 L_NewTest，按设计图 20261020-coins/20261021-platforms/20261020-platform/20261020-door/20261020-progress 批量放置 BP_Coin/BP_Platform/BP_Platform/BP_Door/BP_Progress，然后保存关卡」。规划出 7 扇全可落地（launch → open_level → place_batch×4 + 闸门补 1 扇），**W1/W2 成功，4 扇 place_batch 全部失败**，整句失败，关卡未被改动（放置在第一次 exec 就被拒，无半截状态）。
