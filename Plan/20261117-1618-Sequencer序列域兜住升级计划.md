## 0. 三句话结论

1. Sequencer（过场/关卡序列）**无一等动作**，落 `solve`；工具层有 `SequencerTools`（+ controlrig_sequencer / keyframing）。
2. 缺的是 **LevelSequence Spec + 确定性 kernel + 只读轨道/关键帧复核**：建序列、绑 actor/相机、加 track/section/keyframe、设播放范围。
3. 与“动画关键帧域”高度重叠：Sequencer 是“多条 track 的时间轴容器”，动画关键帧常是其中一条 track。

## 1. 现状与证据

| 项 | 现状 |
| --- | --- |
| 一等动作 | **无** |
| 工具集 | `SequencerTools`、`SequencerControlRigTools`、`keyframing`、`LevelSequence`（描述） |
| 路由实测 | “做一个过场镜头序列，相机从A推到B” → `solve` |
| 验收 | 无；轨道/绑定/关键帧是否正确不可验 |

## 2. 本域“模型-脚本”边界

- **模型**：产 **Sequencer Spec**：新建/打开 LevelSequence、绑定的 actor/相机、轨道列表（Transform/CameraCut/Float/Event/…）、每条轨道的 section 与 keyframe、播放范围（start/end）。
- **脚本**：建序列→按绑定加 track→加 section/keyframe→设 range→保存；**只读复核**：轨道存在、绑定正确、关键帧时间/值读回==Spec、range 对。
- **硬规矩**：模型只产 Spec；写经写闸；track/section/key 类型走白名单。

## 3. Sequencer Spec 草案

```jsonc
{"kind":"level_sequence","asset":"/Game/Cinematics/LS_Intro.LS_Intro","range":[0,5.0],
 "bindings":[
   {"actor":"BP_PlayerCamera","tracks":[
     {"type":"Transform","keys":[{"t":0,"loc":[0,0,0]},{"t":5,"loc":[1000,0,200]}]},
     {"type":"CameraCut","keys":[{"t":0,"on":true}]}
   ]}
 ],
 "verify":["binding:BP_PlayerCamera","track:Transform keys=2","t5 loc==(1000,0,200)","range==0..5","saved"]}
```

## 4. 分期

- **P0 清点（0.5d）**：`scan_mcp_tools --query "level sequence track section keyframe binding camera"` 摸清 `SequencerTools` 的动作与读回。
- **P1 Spec+kernel+读回复核（2–3d）**：`agent/sequencer_spec.py`：建序列/绑 actor/加 track/section/key/range；读回轨道与关键帧比对。
- **P2 相机过场变体（1d）**：CameraCut / 相机绑定 / 焦点；复用动画关键帧（动画域）。
- **P3 回灌修复（1d）**；**P4 沉淀**（“相机推进过场”模板毕业）。

## 5. 守卫

`check_sequencer_spec.py`（track/section/key/range 读回、绑定校验、表外 track 类型拒绝）、`check_sequencer_route.py`（“做过场/相机推进/加相机切换”稳定进链）。登记 `offline.yml`。

## 6. 风险与取舍

- 轨道/关键帧类型多：先做 Transform + CameraCut + Float + Event 四条常用轨。
- “关键帧对”≠“运镜好看”：到“轨道/关键帧读回==Spec”；观感人工。

## 7. 立即三件事

1. 清点 `SequencerTools` 动作与读回。
2. 落 Spec + kernel（Transform/CameraCut）+ 读回复核。
3. `check_sequencer_spec`。

## 8. 关联/基线

- 与动画域（关键帧落 track）、ControlRig（controlrig_sequencer 变体）共用同一个“时间轴/关键帧”抽象。
- 与场景域：绑定的是关卡里的 actor（复用资产定位）。
