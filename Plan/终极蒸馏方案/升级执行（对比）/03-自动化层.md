## 3. 角色 = 工具白名单

在 `roles.py` 增加四个角色，挂到现有 `plan_role` / `tool_allowed`。任务 JSON 可带 `harness_role`，没写时行为不变。

| `harness_role` | 看得见 | 看不见 |

## 6. 记分板

`eval/report.py` 现有汇总之外写 `data/harness/scoreboard.json`。**把统计抽成纯函数** `compute_scoreboard(rows) -> dict`，供检查调用。输入仍是 trace jsonl 或 `data/traces` 目录。没有 usage 留空，不填 0，不估算金额。

```json
{
  "tasks": 0,
  "ok": 0,
  "first_pass": 0,
  "prompt_tokens_per_ok": null,
  "tool_refused": 0,
  "source": "trace 路径"
}
```

`first_pass`：ok 且 retry 0。`tool_refused`：`failure_class == tool_refused` 的次数，两处都有以 `failure_class` 为准。`prompt_tokens_per_ok`：ok 任务 prompt token 合计除以 ok 数；ok 为 0 或无 usage 为 null。

安全硬门槛写进 `documents/harness/scoreboard.md`：工具拒绝是守门成功，不计入 `ok`。
