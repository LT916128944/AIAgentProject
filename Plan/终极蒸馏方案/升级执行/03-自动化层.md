## 6. 记分板

在 `eval/report.py` 把统计抽成纯函数 `compute_scoreboard(rows) -> dict`，现有命令再把结果写入 `data/harness/scoreboard.json`。输入仍是现有 trace jsonl 或 `data/traces` 目录。没有 usage 的字段留空，不填 0，不估算金额。

字段：

```json
{
  "tasks": 0,
  "ok": 0,
  "first_pass": 0,
  "prompt_tokens_per_ok": null,
  "tool_refused": 0,
  "source": "trace 路径"
}
```

`first_pass`：该任务 ok 且 retry 为 0。  
`tool_refused`：失败分类是 `tool_refused` 的次数，或 trace 里拒绝事件的次数；两处都有时以 `failure_class` 为准。  
`prompt_tokens_per_ok`：ok 任务的 prompt token 合计除以 ok 数；ok 为 0 或没有任何 usage 时为 null。

安全硬门槛写在 `documents/harness/scoreboard.md`：工具拒绝是守门成功，不计入 `ok`。不要把拒绝改成通过。
