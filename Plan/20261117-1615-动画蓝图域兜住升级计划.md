# 20261117-1615 — 动画蓝图（AnimBlueprint）域兜住升级计划

- 相关 toolset：`editor_toolset.toolsets.blueprint.BlueprintTools`（AnimBP 本质是蓝图资产）、`editor_toolset.toolsets.skeletal_mesh.SkeletalMeshTools`；**无专用 animBP toolset**

## 0. 三句话结论

1. 动画蓝图**没有专用工具集/一等动作**：它本质是一张 `蓝图(AnimInstance)` 的**动画图 + 状态机**，今天落 `solve`/泛蓝图，兜不住。
2. 好在**蓝图图 kernel（见蓝图域计划）可直接复用**——AnimBP 只是“节点类白名单换成动画节点（SequencePlayer/BlendSpace/StateMachine/Transition）+ 引用 AnimSequence/BlendSpace 资产”。
3. 升级 = 在蓝图图 kernel 上加 **AnimGraph Spec**（状态机/状态/转换/序列播放器/混合）+ 动画资产解析 + 只读图复核 + 编译。

## 1. 现状与证据

| 项 | 现状 |
| --- | --- |
| 一等动作 | **无专用**（仅泛 `create_blueprint/compile_blueprint` + 图任务） |
| 工具集 | `BlueprintTools`（图节点/编译）、`SkeletalMeshTools`（骨骼/插槽/资产） |
| 路由实测 | “做一个动画蓝图，移动时播放跑步动画” → `solve` |
| 验收 | 无专用 kind；图能编过≠状态机对 |

## 2. 本域“模型-脚本”边界

- **模型**：产 **AnimGraph Spec**：目标 AnimBP、状态机（状态/转换/转换条件）、AnimGraph 节点（SequencePlayer→引用 AnimSequence；BlendSpacePlayer→引用 BlendSpace；LayeredBlend…）、变量（Speed 等）。
- **脚本**：用蓝图图 kernel 建状态机/状态/节点/连线/变量 → 编译；**只读复核**：状态机有这些状态/转换、SequencePlayer 引用了正确 AnimSequence、编译过。
- **硬规矩**：模型只产 Spec；写经图写闸 + 编译复核。

## 3. AnimGraph Spec 草案

```jsonc
{
  "anim_blueprint": "/Game/Characters/ABP_Player.ABP_Player",
  "skeleton": "/Game/Characters/SK_Mannequin.SK_Mannequin",
  "variables": [{"name":"Speed","type":"float"}],
  "state_machine": {
    "name": "Locomotion",
    "states": [
      {"name":"Idle","anim":"/Game/Anim/Idle.Idle"},
      {"name":"Run","anim":"/Game/Anim/Run.Run"}
    ],
    "transitions": [
      {"from":"Idle","to":"Run","rule":"Speed > 10"},
      {"from":"Run","to":"Idle","rule":"Speed <= 10"}
    ]
  },
  "verify": ["sm:Locomotion", "state:Run->anim Idle?no", "state:Run anim=Run", "transition:Idle->Run", "compile_ok"]
}
```

## 4. 分期

- **P0 清点（0.5d）**：`scan_mcp_tools --query "animation blueprint state machine anim graph node"` 摸清图工具对动画图/状态机的支持现状（能否建状态机/状态/转换/SequencePlayer）。
- **P1 复用蓝图图 kernel + 动画节点白名单（2d）**：`agent/animgraph_spec.py`：在 `graph_spec` 基础上加动画节点类与 AnimSequence/BlendSpace 资产解析。
- **P2 状态机 Spec + 只读复核（2d）**：读回状态机结构（状态/转换/条件）、SequencePlayer 引用；编译复核。
- **P3 回灌修复（1d）**；**P4 沉淀**（“移动播放跑步”这类模板毕业）。

## 5. 守卫

`check_animgraph_spec.py`（状态机/节点/引用复核、表外动画节点拒绝）、`check_animgraph_route.py`（“做移动动画蓝图/加跳跃状态”稳定进链）。登记 `offline.yml`。

## 6. 风险与取舍

- 动画图节点极多：**先做最小骨架**（状态机 + SequencePlayer + 转换条件），其余按需加白名单。
- 状态机“转换规则”是图逻辑，verifier 到“转换存在 + 条件表达式落了节点”，语义正确性需 PIE/人工。

## 7. 立即三件事

1. 清点图工具对“状态机/动画节点”的支持。
2. 在蓝图图 kernel 上加动画节点白名单 + AnimSequence 解析。
3. 只读状态机 verifier + `check_animgraph_spec`。

## 8. 关联/基线

- 强依赖蓝图域计划（图 Spec/kernel/verifier）；动画资产引用依赖 `SkeletalMeshTools` 和资产索引。
