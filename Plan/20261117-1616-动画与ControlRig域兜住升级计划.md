## 0. 三句话结论

1. 动画（骨骼关键帧动画/ControlRig）**无一等动作**，落 `solve`；但工具层有 controlrig / keyframing / skeletal_mesh / custom_bindings 一族 toolset。
2. 缺的是“**动画关键帧 / ControlRig 图与控件**”的 **Spec + 确定性 kernel + 只读复核**（读回关键帧、控件层级、绑定）。
3. 分两条腿：**A 关键帧动画**（在 Sequence 或 SkeletalMesh 上打 key）与 **B ControlRig**（建 rig 图/控件/绑定）。A 与 Sequencer 域高度重叠，B 与蓝图图 kernel 重叠。

## 1. 现状与证据

| 项 | 现状 |
| --- | --- |
| 一等动作 | **无** |
| 工具集 | `ControlRigTools`、`SequencerControlRigTools`、`keyframing`、`custom_bindings`、`import_export`、`SkeletalMeshTools` |
| 路由实测 | “做一个角色挥手动画，1 秒” → `solve` |
| 验收 | 无；关键帧/控件是否正确不可验 |

## 2. 本域“模型-脚本”边界

- **模型**：产 **Animation Spec**——A：`{skeletal mesh / sequence, bone, property(rot/pos), keyframes:[{t,value}], range}`；B：`{controlrig asset, hierarchy controls:[{name,parent}], rig graph nodes, bindings:[{control, bone}]}`。
- **脚本**：A 用 `keyframing` 打 key 到骨骼/曲线；B 用 `ControlRigTools` 建控件层级/图/绑定；**只读复核**：关键帧读回==Spec（时间/值）、控件层级读回==Spec、绑定存在；资产保存。
- **硬规矩**：模型只产 Spec；写经写闸 + 读回复核。

## 3. Animation Spec 草案

```jsonc
// A：关键帧动画
{"kind":"keyframe_anim","target":"/Game/Characters/SK_Mannequin.SK_Mannequin","bone":"hand_r",
 "channel":"rotation","range":[0,1.0],
 "keys":[{"t":0.0,"value":[0,0,0]},{"t":0.5,"value":[0,60,0]},{"t":1.0,"value":[0,0,0]}],
 "verify":["keys:hand_r.rotation count=3","t0.5==(0,60,0)","saved"]}

// B：ControlRig
{"kind":"controlrig","asset":"/Game/Rigs/CR_Player.CR_Player",
 "controls":[{"name":"ctrl_arm","parent":"root"}],"bindings":[{"control":"ctrl_arm","bone":"upperarm_r"}],
 "verify":["control:ctrl_arm exists","binding:ctrl_arm->upperarm_r","saved"]}
```

## 4. 分期

- **P0 清点（0.5d）**：`scan_mcp_tools --query "keyframe bone animation"` / `"control rig control hierarchy binding"` 摸清 keyframing/controlrig 动作与读回。
- **P1 A 关键帧 Spec+kernel+读回复核（2d）**：`agent/animation_spec.py`。
- **P2 B ControlRig Spec+kernel+读回复核（2–3d）**：控件层级/绑定；rig 图复用蓝图图 kernel。
- **P3 回灌修复（1d）**；**P4 沉淀**（“挥手/走跑循环”模板毕业）。

## 5. 守卫

`check_animation_spec.py`（关键帧读回、控件/绑定读回、表外通道拒绝）、`check_controlrig_spec.py`、`check_animation_route.py`。登记 `offline.yml`。

## 6. 风险与取舍

- 关键帧插值/切线复杂：先做“线性 + 指定关键帧值”，曲线细节后置。
- ControlRig 图 = 图问题：复用蓝图域 kernel，别另写一套。

## 7. 立即三件事

1. 清点 keyframing / controlrig 动作与读回能力。
2. 落 A 级关键帧 Spec + 读回复核。
3. 落 B 级 ControlRig 控件层级 + 只读 verifier。

## 8. 关联/基线

- 与 Sequencer 域：A 级关键帧常落在 LevelSequence 上（复用 Sequencer 的 track/section）。
- 与蓝图域：ControlRig 图复用图 kernel。
