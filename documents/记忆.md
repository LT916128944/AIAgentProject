# 记忆

这里只记项目怎么干活。没有人格、偏好或对话人设。三类是短期、长期项目、错误。反射只发生在 `fix`：先查错误记忆，再把原文交给模型改。分类本身写在 trace 的 `failure_class`，不另做一套人格总结。

枚举在 `RAG/ue-rag/core/failure_class.py`。失败行写入 trace 时带上 code。报告仍显示中文。对不上的失败是 `other`。

| code | 中文 |
| --- | --- |
| `compile` | 编译 |
| `test` | 测试 |
| `tool_refused` | 工具拒绝 |
| `mcp_down` | MCP 连不上 |
| `retry_exceeded` | 超过重试 |
| `level_precheck` | 关卡预检 |
| `other` | 其他 |

旧 trace 没有这个字段时，`eval/report.py` 仍按 `judge_kind` 和错误原文归到同一张表。行里已经有合法 code 时，以 code 为准。
